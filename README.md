เพิ่มแหล่งใหม่ได้โดยแก้ตัวแปร `SOURCES` ใน `fetch-news.mjs` (เว็บ WordPress ส่วนใหญ่มี feed ที่ `/feed/`)

## โครงสร้าง

```
fetch-news.mjs                  สคริปต์ดึงข่าวจาก RSS → data/news.json (ใช้ Node อย่างเดียว ไม่ต้องติดตั้งอะไร)
data/news.json                  ข้อมูลข่าวล่าสุด (สร้างอัตโนมัติ)
index.html                      หน้าเว็บ อ่านข้อมูลจาก data/news.json
.github/workflows/update-news.yml   ตั้งเวลาให้ GitHub รันสคริปต์ทุก 1 ชั่วโมงโดยอัตโนมัติ
```

## ทดลองรันในเครื่อง

```powershell
node fetch-news.mjs        # ดึงข่าวล่าสุด
npx serve .                # เปิด local server แล้วเข้า http://localhost:3000
```

(เปิดไฟล์ index.html ตรง ๆ ไม่ได้ เพราะเบราว์เซอร์บล็อกการอ่าน news.json จาก file://)

## ทำให้อัตโนมัติ 100% (ฟรี)

1. สร้าง repository บน GitHub แล้ว push โฟลเดอร์นี้ขึ้นไป
2. ไปที่ **Settings → Pages** เลือก Deploy from branch `main` → เว็บจะออนไลน์ที่ `https://<username>.github.io/<repo>/`
3. เสร็จแล้ว — GitHub Actions จะรัน `fetch-news.mjs` ทุก 1 ชั่วโมง, commit ข้อมูลใหม่, และหน้าเว็บอัปเดตเองโดยเราไม่ต้องทำอะไรเลย

## หมายเหตุเรื่องลิขสิทธิ์

เว็บนี้แสดงเฉพาะ**หัวข้อ + สรุปย่อ + ลิงก์กลับไปต้นทาง** (ข้อมูลจาก RSS ที่แหล่งข่าวเปิดเผยเพื่อการเผยแพร่อยู่แล้ว) ไม่คัดลอกเนื้อหาเต็ม และให้เครดิตแหล่งที่มาทุกข่าว
