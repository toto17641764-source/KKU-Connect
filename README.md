# KKU Connect 🏫

เว็บไซต์รวมข่าวสารของ**มหาวิทยาลัยขอนแก่น** แยกตามคณะ/วิทยาลัยทั้งหมด ที่**อัปเดตอัตโนมัติ** — ดึงหัวข้อข่าวจากแหล่งที่เชื่อถือได้ แสดงผลในดีไซน์ของเราเอง และลิงก์กลับไปอ่านฉบับเต็มที่ต้นทาง

> ออกแบบตามเอกสาร KKU CONNECT (ปัญหา: นักศึกษาพลาดข่าวสารสำคัญเพราะข้อมูลกระจายหลายช่องทาง → รวมไว้ที่เดียว กรองตามคณะได้)

## แหล่งข่าว

ดึงจาก 2 ทางประกอบกัน:

1. **RSS ทางการของเว็บคณะ** (คณะที่เปิดใช้: วิทยาศาสตร์ · ศึกษาศาสตร์ · ทันตแพทยศาสตร์ · สถาปัตยกรรมศาสตร์ · บริหารธุรกิจและการบัญชี · ศิลปกรรมศาสตร์ · วิทยาลัยการปกครองท้องถิ่น) — ได้ข่าวตรงจากคณะพร้อม**รูปประกอบ**
2. **Google News RSS** รายคณะ (ค้นด้วยชื่อคณะ + "มหาวิทยาลัยขอนแก่น") สำหรับคณะที่เหลือและข่าวจากสำนักข่าวภายนอก

ทุกคณะมีปุ่มลิงก์ไป**เว็บไซต์คณะ**และ**เพจ Facebook ทางการ**ในหน้าเว็บ (Facebook ไม่เปิดให้ดึงโพสต์อัตโนมัติ จึงลิงก์ไปที่เพจโดยตรง)

ครอบคลุม **คณะ/วิทยาลัยทั้งหมด 24 แห่ง** ของ มข. + ข่าวรวมระดับมหาวิทยาลัย:

แพทยศาสตร์ · วิศวกรรมศาสตร์ · วิทยาศาสตร์ · เกษตรศาสตร์ · ศึกษาศาสตร์ · พยาบาลศาสตร์ · มนุษยศาสตร์และสังคมศาสตร์ · ทันตแพทยศาสตร์ · เภสัชศาสตร์ · เทคนิคการแพทย์ · สาธารณสุขศาสตร์ · สัตวแพทยศาสตร์ · เทคโนโลยี · สถาปัตยกรรมศาสตร์ · บริหารธุรกิจและการบัญชี · ศิลปกรรมศาสตร์ · นิติศาสตร์ · เศรษฐศาสตร์ · สหวิทยาการ (หนองคาย) · วิทยาลัยการคอมพิวเตอร์ · วิทยาลัยการปกครองท้องถิ่น · วิทยาลัยนานาชาติ · บัณฑิตวิทยาลัย · วิทยาลัยบัณฑิตศึกษาการจัดการ

เพิ่ม/แก้แหล่งได้ที่ตัวแปร `FACULTIES` ใน `fetch-news.mjs`

**เว็บนี้คัดเฉพาะข่าวที่มีประโยชน์ต่อนักศึกษา** — หัวข่าวต้องเกี่ยวกับ นศ./ทุน/การรับเข้า/กิจกรรม/ฝึกงาน-สายอาชีพ/บริการนักศึกษา จึงจะแสดง ข่าวองค์กร ข่าวคดี ข่าวการเมือง และ PR ผู้บริหารถูกกรองออกอัตโนมัติ (ดูกติกาที่ `STUDENT_KEEP` และ `EXCLUDE_RULES` ใน `fetch-news.mjs`)

## ฟีเจอร์หน้าเว็บ

- **ดีไซน์ตาม wireframe ใน KKU CONNECT.pdf** — หน้าแรก (สไลด์ข่าวเด่น + แนะนำสำหรับคุณ + ข่าวสารล่าสุด + กิจกรรมที่กำลังจะมาถึง) และหน้ารายละเอียดข่าวพร้อม**กล่องสรุปข่าวโดย AI** (สรุปจำลองจากหัวข่าว/หมวด/วันที่ ไม่ได้เรียก AI จริง) + **AI แนะนำข่าวที่เกี่ยวข้อง** + ปุ่มแชร์ LINE/Facebook/X
- **หมวดหมู่ข่าว 7 หมวด** — ประกาศ · การศึกษา · ทุนการศึกษา · กิจกรรม · รับสมัครงาน · วิจัย · อื่นๆ (จัดหมวดอัตโนมัติจากคำสำคัญในหัวข่าว ดูกติกาที่ `TOPIC_RULES` ใน `fetch-news.mjs`)
- **แยกข่าวตามคณะ** — เมนู "ดูรายคณะ" กดเปิด/ปิดรายชื่อคณะทั้ง 24 แห่ง เลือกแล้วกรองทันที (มือถือเป็นแถบเลื่อนด้านบน)
- **ค้นหา** — พิมพ์ค้นหัวข้อข่าวได้ทุกคณะ
- **บันทึกข่าว / ตั้งเตือน** — กด 🔖 เก็บข่าวไว้อ่านทีหลัง หรือ 🔔 ตั้งเตือนไว้ดูในหน้าการแจ้งเตือน (เก็บใน localStorage ของเครื่อง)
- **การแจ้งเตือน** — หน้ารวมข่าวใหม่ใน 48 ชั่วโมงล่าสุด (กระดิ่งบนหัวเว็บก็เปิดดูได้)
- **ตั้งค่า** — เปิด/ปิดแบนเนอร์, จำนวนข่าวต่อหน้า, เลือกหน้าเริ่มต้น (คณะ/หมวดที่สนใจ), ล้างรายการบันทึก
- โปรไฟล์เป็น UI จำลองตาม wireframe (การเข้าสู่ระบบและแจ้งเตือนแบบพุชเป็นแผนพัฒนาต่อ)

## โครงสร้าง

```
fetch-news.mjs                  สคริปต์ดึงข่าว → data/news.json (ใช้ Node อย่างเดียว ไม่ต้องติดตั้งอะไร)
data/news.json                  ข้อมูลข่าวล่าสุด (สร้างอัตโนมัติ)
index.html                      หน้าเว็บ อ่านข้อมูลจาก data/news.json
.github/workflows/update-news.yml   ตั้งเวลาให้ GitHub รันสคริปต์ทุก 1 ชั่วโมงโดยอัตโนมัติ
```

## ทดลองรันในเครื่อง

```powershell
node fetch-news.mjs        # ดึงข่าวล่าสุด
npx serve .                # เปิด local server แล้วเข้า http://localhost:3000
```

(เปิดไฟล์ index.html ตรง ๆ ไม่ได้ เพราะเบราว์เซอร์บล็อกการอ่าน news.json จาก file://)

## ทำให้อัตโนมัติ 100% (ฟรี)

1. push ขึ้น GitHub แล้วไปที่ **Settings → Pages** เลือก Deploy from branch `main`
2. GitHub Actions จะรัน `fetch-news.mjs` ทุก 1 ชั่วโมง, commit ข้อมูลใหม่, และหน้าเว็บอัปเดตเองโดยไม่ต้องทำอะไรเลย

## หมายเหตุเรื่องลิขสิทธิ์

เว็บนี้แสดงเฉพาะ**หัวข้อข่าว + ชื่อสำนักข่าว + ลิงก์กลับไปต้นทาง** (ข้อมูลจาก RSS ที่เปิดเผยเพื่อการเผยแพร่อยู่แล้ว) ไม่คัดลอกเนื้อหาเต็ม และให้เครดิตแหล่งที่มาทุกข่าว — ไม่ใช่เว็บไซต์ทางการของมหาวิทยาลัยขอนแก่น
